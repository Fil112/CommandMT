## 📖 О плагине

**CommandMT** — это современная и оптимизированная альтернатива устаревшим менеджерам команд (таким как MyCommand). Плагин позволяет создавать собственные команды, алиасы, цепочки действий и текстовые ответы на лету, используя удобный формат файлов `.mt`.

Никаких перезапусков сервера и прописывания команд в `plugin.yml` — CommandMT динамически инжектит команды напрямую в ядро сервера, обеспечивая полную поддержку Tab-комплита.

## ✨ Главные фишки

* **Динамическая регистрация:** Команды появляются, обновляются и удаляются из памяти сервера моментально при перезагрузке конфига.
* **Кастомный формат `.mt`:** Удобная структуризация команд по отдельным файлам в папке `command/`.
* **5 типов команд:**
    * `TEXT` — вывод многострочного текста.
    * `CONSOLE_COMMAND` — выполнение цепочки команд от лица консоли.
    * `RUN_COMMAND` — принудительное выполнение команд от лица игрока.
    * `BROADCAST_TEXT` — глобальные оповещения на весь сервер.
    * `ALIAS` — умные сокращения с пробросом аргументов.
* **Плейсхолдеры:** Встроенная поддержка переменных (например, `$player` заменяется на никнейм).
* **Мультиязычность:** Выбор между RU и EN локализациями прямо "из коробки" в глобальном `config.yml`.
* **Широкая поддержка:** Скомпилирован под Java 8, стабильно работает на любых ядрах (Spigot/Paper) от версии 1.16 до самых актуальных.

## 🚀 Установка

1. Скачайте актуальную версию `CommandMT.jar`.
2. Поместите файл в папку `plugins/` вашего сервера.
3. Запустите или перезагрузите сервер.
4. Перейдите в `plugins/CommandMT/command/`, изучите примеры (`example_ru.mt`) и создайте свои уникальные команды!

## 🛠️ Примеры конфигурации

Вы можете создавать неограниченное количество `.mt` файлов для сортировки логики.

```yaml
# Пример текстовой команды
discord_command:
  command: /discord
  type: TEXT
  aliases:
    - /ds
  text:
    - "&9Наш Discord: &f[https://discord.gg/yourlink](https://discord.gg/yourlink)"

# Пример выдачи бонуса (от консоли)
free_bonus:
  command: /bonus
  type: CONSOLE_COMMAND
  runcmd:
    - "give $player diamond 1"
    - "tell $player &aВы получили алмаз!"

# Пример алиаса (сокращения)
creative_mode:
  command: /gmc
  type: ALIAS
  alias-to: "gamemode creative"# CommandMT
